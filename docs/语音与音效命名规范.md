> 一句话：**音效我已经全做好了（27 个文件，不用你管）；你只需要把裁好的动漫语音按下面的规则丢进文件夹。**

│  ├─ 无下限_1.mp3

│  ├─ 黑闪_1.mp3
│  ├─ 受击_1.mp3
│  ├─ 胜利_1.mp3
│  └─ 失败_1.mp3
├─ 宿傩/
│  ├─ 解_1.mp3
│  ├─ 捌_1.mp3
│  ├─ 灶开_1.mp3
│  ├─ 伏魔御厨子_1.mp3
│  ├─ 黑闪_1.mp3

│  └─ 失败_1.mp3

**文件夹名字必须是「五条悟」「宿傩」**（和角色数据里的 `voiceDir` 一致）。
以后加新角色时，在 `src/data/characters.js` 里给 `voiceDir` 写什么名字，就用什么文件夹名。

支持格式：`.mp3` `.wav` `.ogg` `.m4a`（优先推荐 mp3）。

## 2. 文件名规则（两种写法都支持）

### 写法 A：带序号（推荐，同一句话可以准备多条随机播）
```
苍_1.mp3    苍_2.mp3    苍_3.mp3
```
释放「苍」的时候，游戏会**从这三条里随机挑一条**播放。
只放一条也没问题；一条都没有就安静地跳过（不会报错、不会卡）。

### 写法 B：任意文件名
```
五条悟-苍.mp3        赫（2）.mp3        大招_无量空处.mp3
```
末尾的序号会被自动剥掉，剩下的名字必须**正好等于**下面表里的语音键。

> 名字对不上会怎样？不会崩，只是那条语音永远不会播。
> 具体对不上的，运行 `node tools/scan_voice.js` 会直接列出来告诉你。

## 4. 加完语音之后要做的一步

```
node tools/scan_voice.js
```

它会：
1. 扫描两个文件夹，生成/更新 `src/assets/audio/voice/manifest.js`
   （游戏优先读这个清单，所以写法 B 的任意文件名也能被识别）
2. 打印一张对照表：**已有 / 缺失 / 名字对不上**，一眼就能看出哪里错了

`manifest.js` 已经预置在 `index.html` 里了，不需要你再改任何代码。

## 5. 播放规则（涉及音量与重叠）

- 语音永远**叠加在音效之上**播放：技能音效照常响，语音额外叠加，互不干扰。
- 同一条语音键 **180ms 内不会重复播**（防止连点技能刷屏）。
- 音效和语音的音量在游戏「设置」里**分开调**。
- 语音比音效整体晚一点点触发（跟同一帧的音效一起起播），听感上是"音效打底 + 人声压上"。

## 5.5 背景音乐（自备）

游戏默认放的是我合成的 25 秒循环 BGM。想换成自己的音乐：

1. 把音乐文件放进 `src/assets/audio/bgm/`
2. 文件名（去掉后缀）要等于 `src/data/characters.js` 里的 `audio.userBgm`
   —— 现在填的是 `RainieLove`

目前的状态：**已经放好了 `RainieLove.mp4`，游戏会自动用它。**

支持的扩展名（按顺序找，找到就用）：`.mp3` `.m4a` `.mp4` `.ogg` `.wav` `.aac`
找不到文件会自动回退到内置 BGM，不会报错。

> 关于 `RainieLove.mp4`：这个原始文件其实是一个 **MP4 容器（H.264 视频 + 音轨）**，
> 只是扩展名写成了 `.mp3`。手机浏览器（尤其 iOS）是按扩展名判断类型的，
> 名字和容器对不上可能直接不播，所以我把它改成了 `.mp4`。
> `<audio>` 播放 MP4 时只会取音轨（实测 videoWidth = 0，时长 197.1 秒）。

音量在游戏「设置 → 背景音乐」里单独调，和音效/语音音量是分开的三条。
## 6. 内置音效清单（我已做好，不用你提供）

`src/assets/audio/sfx/` 下 27 个文件，全部为程序化合成（numpy 生成，16bit / 44.1kHz / 单声道）：

| 分类 | 文件 |
|---|---|
| 界面 | `ui_click` `ui_hover` `countdown` `round_start` `victory` `defeat` |
| 命中 | `hit_generic` `hit_slash` `hit_heavy` `explosion` `bounce_wall` `bounce_ball` `hurt` `immune_block` `black_flash` |
| 技能 | `cast_gojo1_blue` `cast_gojo1_red` `cast_murasaki` `cast_gojo2` `cast_gojo3` `cast_sukuna1` `cast_sukuna1_grid` `cast_sukuna2` `cast_sukuna3` |
| 领域 | `domain_tick` |
| 音乐 | `bgm_menu` `bgm_battle` |

**想换音效**：直接替换同名 `.wav` 文件即可，代码不用改。
**想重新合成**（改了参数想重跑）：
```
& "<你的 python>" tools/gen_sfx.py            # 全部重生成
& "<你的 python>" tools/gen_sfx.py --only black_flash   # 只重生成一个
& "<你的 python>" tools/gen_sfx.py --analyze            # 打印体检表
```
脚本用 numpy + 标准库 wave，不依赖 scipy / soundfile。
