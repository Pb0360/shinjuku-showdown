# iPad 适配说明

**结论：能玩，而且已经专门做了适配。** 但装到 iPad 上有两种方式，差别很大，先说最关键的限制。

---

## ⚠️ 关键限制：装到桌面（离线玩）必须走 HTTPS

游戏是网页应用，用 Safari 直接打开就能玩。但如果你想**「添加到主屏幕」得到一个全屏、离线可玩的图标**，
需要 Service Worker 把资源缓存到本地 —— 而浏览器规定：

> **Service Worker 只能在「安全上下文」里运行：HTTPS，或 localhost。**
> `http://192.168.x.x:8080` 这种局域网 IP **不算安全上下文**，Service Worker 会被禁用。

所以：

| 方式 | 能玩 | 能装到桌面 | 离线 | 需要 |
|---|---|---|---|---|
| 局域网（`npm run web`） | ✅ | ❌ | ❌ | 电脑一直开着 |
| **HTTPS 托管（推荐）** | ✅ | ✅ | ✅ | 一个静态托管地址 |
| 真正的 iOS App | ✅ | ✅ | ✅ | Mac + Xcode + 99$/年开发者账号 |

---

## 方式 A（推荐）：丢到静态托管上，iPad 就能装了

`src/` 是纯静态文件，路径全是相对的，放到任何地方都能跑。

**最省事的三个选择：**

1. **Netlify Drop** — <https://app.netlify.com/drop>　把 `src` 文件夹整个拖进去，
   几十秒后会给你一个 `https://xxx.netlify.app` 地址（不需要注册就能拿到临时地址）
2. **Vercel** — <https://vercel.com>　导入项目，发布目录填 `src`
3. **GitHub Pages** — 把 `src/` 里的内容推到仓库的 `gh-pages` 分支

拿到 `https://...` 地址后，在 iPad 上：

1. **Safari**（必须用 Safari，Chrome 在 iOS 上加不了主屏幕）打开那个地址
2. 点顶部/底部的 **分享按钮** → **添加到主屏幕**
3. 桌面会出现「新宿对决」图标，点开就是**全屏、无浏览器边框、离线可玩**

> 启动时会先显示一张米白色启动图（我做了 10 张覆盖各代 iPad 的横竖屏），不会白闪。

**注意**：第一次打开要让它完整加载一次（缓存需要时间，有 4.6MB 的背景音乐），
之后就算断网、电脑关机也能玩。改完游戏代码要重新部署，iPad 上再打开一次才会更新缓存。

---

## 方式 B（最快，但只适合临时玩）：局域网直连

```powershell
npm run web
```
终端会打印一个 `http://192.168.x.x:8080/` 地址，iPad 连同一个 WiFi，用 Safari 打开即可。

- ✅ 立刻能玩，不需要任何部署
- ❌ 不能「添加到主屏幕」（因为没有 HTTPS，装上去也只会是个书签，打开还是浏览器界面）
- ❌ 电脑必须开着

## 已经为 iPad 做的适配

| 项目 | 说明 |
|---|---|
| **横屏布局** | iPad 横屏时**技能栏自动挪到右侧竖排**，方形场地吃满整个高度 —— 场地从 516px 变成 **604px**（12.9 寸上 720 → **808px**），大了 12~17% |
| **按钮尺寸** | 触屏设备上按钮放大到 **196~214 × 104~108px**，两个拇指按得舒服 |
| **触控响应** | 技能按钮改成监听 `pointerdown` 而不是 `click`，按下即触发，比传统点击快一截 |
| **禁掉 iOS 的干扰** | 禁止长按弹菜单（`-webkit-touch-callout`）、禁止双击缩放、禁止橡皮筋回弹（`overscroll-behavior`）、禁用文本选择 |
| **安全区** | 适配刘海屏 / Home 指示条（`env(safe-area-inset-*)`），横屏时按钮不会被指示条压住 |
| **旋转重算** | 屏幕旋转时在 120ms / 320ms / 700ms 三次重新计算画布尺寸，并监听 `visualViewport`（iOS 上比 resize 更及时） |
| **启动图** | 10 张（10.2" / 10.9" / 11" / 12.9" / mini 的横竖屏），共 0.5MB |
| **音频** | iOS 要求先有一次用户点击才允许出声 —— 点「开始对决」即可解锁；如果音乐因为自动播放策略被拦下，第一次点击后会自动重试 |

## 怎么在 iPad 上自己验证布局

```powershell
node tools/smoke.js --ipad
```
会用无头 Chrome 按 iPad 的三种尺寸（1180×820 / 820×1180 / 1366×1024）跑一遍，打印布局数据并出图到 `tools/shots/`：

```
iPad ipad-land      (1180x820):  场地 604×604  技能按钮 214×104  无溢出
iPad ipad-port      (820x1180):  场地 798×798  技能按钮 196×108  无溢出
iPad ipad-12.9-land (1366x1024): 场地 808×808  技能按钮 214×104  无溢出
```

## 如果想要真正的 iOS App（.ipa）

必须：一台 **Mac** + **Xcode** + **Apple 开发者账号（99 美元/年）**，用 Capacitor 的 iOS 平台打包：

```bash
npm install @capacitor/ios
npx cap add ios
npx cap sync ios
npx cap open ios      # 在 Xcode 里签名、连 iPad、Run
```

免费账号也能签，但**签名只有 7 天**，过期要重新连电脑刷一次；想长期用就得买开发者账号。
另外 iOS 不允许侧载，ipa 不能像 apk 那样随便发给别人装 —— 所以**对「发给朋友玩」这个目标，PWA 才是正解**。
