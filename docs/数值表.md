> **苍 的吸附力实测**（`node tools/probe-attract.js`，球速 400 从旁边掠过 / 测 1 秒后的方向偏转）：
>
> | 掠过时的横向偏移 | 50 | 110 | 170 | 220 |
> |---|---|---|---|---|
> | 对**球**的偏转（当前） | +29° | **+78°** | +60° | +4° |
>
> 历史对照（偏移 110 处对球的偏转）：**加速 260 → 3°**（等于没有吸附力）
> → **1200 → 29°** → **2400 + falloff 0.6 → 78°**。
>
> **真实对局里的实测**（这段才是关键）：
> - 对手的球每局有 **8.37 秒**待在力场里（占对局时长 28%）
> - 累计被施加 **11,188 单位/秒**的速度增量（球本身速度才 400）
> - 也就是说机制一直在生效，**"看不见"是因为球没有拖尾、曲线没有参照物**
>
> 所以现在加了三层可视反馈：
> 1. **球体运动拖尾**（18 段渐隐残影）——被拽弯的轨迹一眼看出来
> 2. **向内收缩的引力环**（4 圈不断向圆心收）——这个圈里在吸，静态也能看出来
> 3. **吸力流线**——被吸住的物体与苍之间有向内滑动的小点
>
> 「赫」往往在偏转角度显现之前就**被抓走合成茈了**，所以脚本量到的赫偏转反而变小 ——
> 那不是吸力变弱，是直接被吞了。

### 迳庭拳的参数敏感性（每一轮实测都记在这里）

改之前他是 40.7% / 19.2%（最弱），改成 `cd 0.3 + 每下 23 点` 之后是 **92% / 85%**。

**不只是 DPS 的问题 —— 0.3 秒 CD 会造成"击飞锁定"：**
每 0.3 秒就把对手以 950 的速度轰出去，对手永远在飞、永远没法站定放技能。
证据：同样每下 14 点，`cd 0.3` 是 63/28%，而 `cd 0.5` 只有 37/16% —— CD 越短，
哪怕伤害一样也强得多，因为对手被剥夺了出手机会（五条悟的出手次数从 24.5 掉到 18.6 甚至更低）。

**0.3 秒 CD 下，每下伤害是"刀尖上的平衡"（每个对局 1200 局）：**

| 配置 | vs 五条悟 | vs 宿傩 | 综合 |
|---|---|---|---|
| cd 0.3 + 23 点/次（当前） | 92.9% | 85.7% | **89.3%** |
| cd 0.3 + 17 点/次（1×9+8） | 82.8% | 55.4% | 69.1% |
| cd 0.3 + 14 点/次（1×9+5） | 62.9% | 27.7% | 45.3% |
| cd 0.3 + 12 点/次（1×9+3） | 46.8% | 18.3% | 32.5% |
| cd 0.3 + 9 点/次（1×9+0） | 34.4% | 10.0% | 22.2% |
| cd 0.4 + 14 点/次 | 42.8% | 19.6% | 31.2% |
| cd 0.5 + 23 点/次 | 80.5% | 56.1% | 68.3% |
| cd 0.6 + 23 点/次 | 80.5% | 53.6% | 67.0% |

**读出来的结论：**
- 伤害从 12 → 23（不到 2 倍），综合胜率从 32% → 89%。这个位置**极其敏感**，不适合用"每下多少点"当粗调旋钮。
- `cd ≥ 0.5` 之后 CD 就基本不再是约束了（0.5 和 0.6 数字几乎一样），限制变成了"能不能贴上"。
- 23 点/次在任何 CD 下都偏强（0.6 秒时还有 80/54）。

**为什么数据上是弱的 —— 打不过宿傩是因为"打不到人"：**
宿傩的输出全部来自远程与范围（解 407、灶·开 322、伏魔御厨子 211、捌 198），
而虎杖只能贴身。51 秒的局里他只打出 963 点，宿傩却打了他 1287 点 ——
纯粹的对拼输了，不是运气问题。

**那为什么"感觉很强"：**
黑闪那一拳是 243 点 + 自己回满血，是一次性的大数字；加上 1 秒 CD 的迳庭拳贴身连打，
被贴住的时候压迫感非常强。但这些是"高光时刻"，总量上他是亏的。
另外 AI 玩五条 / 宿傩的远程体系比人玩得好，所以你实际对上的虎杖会比这个胜率更强一些。

**参数扫描（`node tools/sweep-yuji.js`，每个对局 1200 局，括号=相对基线的变化）：**

| 改动 | vs 五条悟 | vs 宿傩 |
|---|---|---|
| 现状（基线 40.3 / 17.5） | — | — |
| 迳庭拳 `hits` 2 → 3 | **+35.8** | **+24.8** |
| 迳庭拳 `range` 200 → 280 | +17.3 | +9.8 |
| 迳庭拳 `cd` 1.0 → 0.6 | +14.3 | +7.8 |
| 血量 800 → 1000 | +28.2 | +9.1 |
| 黑闪 `cd` 60 → 40 | +37.2 | +1.8 |
| 移动速度 +30% → +45% | +2.3 | +1.4 |
| `hits` 3 + `cd` 1.4 | 50.6% | 24.9% |
| `hits` 3 + `cd` 1.6 + `range` 300 | 65.3% | 31.8% |

**从数据里读出来的两件事：**

1. **凡是提升 DPS 的改动（hits / range / cd），两个对局一起涨；
   其它改动（血量、黑闪 CD）几乎只对五条悟有效。**
   因为对宿傩他是在 32 秒内就被打死的，血量再多也只是多撑一会儿，
   黑闪从 60 秒降到 40 秒也还是只能用一次。
2. **不存在一个数字能让两个对局都落在 50%。** 把宿傩那场拉到 50% 需要的力度
   （例如 `hits 3 + range 280`）会把五条那场顶到 89%。
   所以这是**结构问题**（纯近战 vs 纯远程），不是数字问题。

**如果要动，我的建议顺序：**
1. 先给迳庭拳一点"够得着"的能力（`range` 200 → 260~300），这是唯一对宿傩有效的方向；
2. 再把 `hits` 加到 3，同时把 `cd` 从 1.0 拉到 1.4~1.6 抵消过冲（DPS 从 18 变成 17~19，几乎不变，
   但每一次的爆发更集中）；
3. 如果还是不够，再考虑血量。

想调就按这个顺序动（都在 `src/data/characters.js` 的 `yuji` 里）：

| 旋钮 | 位置 | 现值 | 说明 |
|---|---|---|---|
| 血量 | `yuji.hp` | 800 | 最直接的一档 |
| 迳庭拳伤害 | `yuji.skills[0].punch.hits` | 2 | 改成 3 就是 27 点/次 |
| 迳庭拳射程 | `...punch.range` | 200 | AI 现在只在 ≤250 才出手，射程越大出手窗口越多 |
| 迳庭拳 CD | `yuji.skills[0].cd` | 1.0 | 36.6 次/局，基本已经打满 |
| 黑闪 CD | `yuji.skills[1].cd` | 60 | 降到 30 就是每局 2 发必定黑闪 |
| 弹开力度 | `...punch.knockback` | 620 | 越大越安全，但也越难追击 |

> ⚠️ 黑闪的"CD 全清"**不清大招**（见 `ball.js:resetCooldowns`）。
> 否则「黑闪(大招) → 迳庭拳 → 必定黑闪 → CD 全清 → 黑闪…」会无限循环：
> 修之前实测每局 4.2 次黑闪、100% 对局触发、虎杖胜率 98%。

> 血量翻倍曾把胜率推到 80/20（因为五条悟的被动按【最大生命百分比】回血，
> 血量和对局时长同时翻倍 → 回复量涨了 4.3 倍）。
> 把反转术式的结算间隔从 2 秒延长到 2.5 秒之后，回复量 307 → **247**，胜率回到 46/53。

> 这一版把胜率从 26% 拉回 47% 的**不是数值微调，而是"赫 优先合成茈"这个规则**：
> 以前赫 撞在苍里的敌人身上直接炸掉，茈 每局只合出 0.56 次；
> 现在每局合出 **1.08 次**，而茈 单次平均打 **87 点**（伤害 +60%、体型 +30% 之后）。
