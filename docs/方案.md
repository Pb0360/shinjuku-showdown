# 新宿对决 — 制作方案 v1.0

> **注意**：本文是立项时的设计案，里面第 3、4 章的具体数值是初稿。
> **当前真实数值以 [`数值表.md`](数值表.md) 和 `src/data/characters.js` 为准**
> （后来为了把球球碰撞次数从 2 次/局提到 7 次/局，场地从 1000 缩到了 720，
> 所有技能几何尺寸也跟着重算过；平衡也实测调过一轮）。

弹球对战游戏：玩家与系统各操控一个会弹性反弹的"角色球"，双方都不能直接控制球的移动，
只能通过释放技能（弹幕 / 增益 / 领域）来赢得对局。先说结论：**没有走位，只有时机与运气**——
这是一款"弹球 + 技能时机 + 赌黑闪"的对局游戏。

---

## 0. 已确认的决策

| 项 | 决定 |
|---|---|
| 技术路线 | HTML5 + Canvas 网页核心（零框架、零外部依赖）→ Electron 打包 exe，Capacitor 打包 apk |
| 场地 | 纯净空场，四面墙完全弹性反弹，无重力、无摩擦（俯视视角） |
| 对局 | 单局定胜负，一方血量归零结束 |
| 美术 | 纯几何风：米白底 + 角色配色能量球 + 名字标签（无立绘、无版权素材） |
| 语音 | 每个技能支持多条随机语音；技能释放/命中/受击/黑闪等**音效由我合成**，语音是叠加层 |
| AI | 固定一档平衡 AI，数值恒定；双方角色可任选（五条悟 vs 宿傩 / 宿傩 vs 五条悟 / 内战） |
| 平衡验证 | 提供无头模拟工具，机器 vs 机器批量跑胜率与对局数据 |

## 2. 核心规则（通用）

| 项 | 数值 |
|---|---|
| 场地 | 逻辑坐标 1000 × 1000 正方形，按屏幕等比缩放并居中 |
| 球半径 | 五条悟 34 / 宿傩 36 |
| 初速 | 260 单位/秒，随机方向，随机起始位置（离对手至少 350） |
| 速度上限 | 900 单位/秒 |
| 墙反弹 | 完全弹性，速度不衰减 |
| 碰撞伤害 | 4 点，同一对球 0.5 秒内不重复结算 |
| 碰撞伤害类型 | 直伤（无下限不能免疫） |
| 黑闪 | 每次球球碰撞结算时 2.5% 概率触发（已锁定） |

### 伤害类型（这是整套平衡的骨架）

| 类型 | 包含 | 无下限术式能否免疫 |
|---|---|---|
| **弹幕** | 苍、赫、茈、解、捌、灶·开直击与灼烧、伏魔御厨子斩击 | ✅ 能 |
| **直伤** | 球体碰撞、黑闪、无量空处、被领域展延强化过的命中 | ❌ 不能 |

> 宿傩的被动「领域展延」把攻击 20% 概率变成直伤，正好穿透五条悟的无下限 —— 还原原作克制关系，
> 也是两边胜率能咬住的关键。

## 3. 五条悟（500 HP）

### 一技能「术式顺转·苍 / 术式反转·赫 / 虚式·茈」
**充能：2 点，每点 3.2s 回充，开局满 2 点；每次释放消耗 1 点，苍/赫 各 50% 随机**

| 招式 | 参数 |
|---|---|
| 苍 | 半径 30，速度 190（慢），存在 5s；**吸引半径 220 内的飞行物与敌方球**（加速度 260/s²，越近越强）；接触敌人每 0.18s 造成 6 点弹幕伤害（站桩吃满约 168） |
| 赫 | 半径 10（极小），速度 620（快）；命中敌人或墙壁**立即爆炸**：直击 30 + 爆炸半径 95（中心 35，边缘衰减到 12）；单段 |
| 茈 | 赫 在飞行中撞到场上的 苍 → **在苍的位置合成**；半径 55 → 0.45s 内膨胀到 80；存在 2.4s；接触敌人每 0.12s 造成 12 点（约 200）；结束时爆炸半径 160 造成 60 点。无独立 CD |

> 苍的引力是全局唯一的"间接位移"手段：它能把对手球拖向自己，也能把敌方飞行物拽偏。

### 二技能「无下限术式」
- 充能 3 点，每点 6.5s，开局满 3 点
- 释放后 **0.2s 内免疫所有弹幕伤害**
- 免疫期间接触到的敌方飞行物被**反弹**（速度反向 ×1.6，归属改为原主，伤害取其 60%）
- 若这 0.2s 内**真的挡下了**至少 1 次本会命中的弹幕伤害 → 特效加大 + **免疫延长到 0.5s**
- 直伤照吃（碰撞、黑闪、无量空处、领域展延强化命中）

### 三技能「领域展开·无量空处」（大招）
- CD 40s，开局即可用
- 1.0s 领域展开演出 → 对敌方造成 **10 段 × 10 = 100 点直伤**，每段间隔 0.1s
- 直伤，无下限免疫不了；球无法走位所以必中 —— 这就是大招的定位

### 被动「反转术式」
- 每 2s 恢复最大生命 1%（5 点）
- 若这 2s 内未受到任何伤害，**额外**恢复已失去生命的 2%
- 一局期望总回复约 30~80 点

## 4. 宿傩（600 HP）

### 一技能「解 / 捌」
**判定：与敌人距离 < 180 → 捌；否则 → 解**（同一个按钮，自动切换）

| 招式 | 参数 |
|---|---|
| 解 | CD 2.2s；向敌人方向射出一字型刀光（长 1200、宽 46、速度 1600）；命中造成 22 点弹幕伤害，单段 |
| 捌 | CD 4.0s；在敌人位置展开 3×3 网格斩击（格边长 90，覆盖半径约 160）；每格 14 点，同一目标最多结算 4 格（合计 56） |

### 二技能「灶·开」
- CD 11s，向敌人方向射出火焰箭（速度 700，半径 14）
- 命中：直击 45 点弹幕伤害 + **灼烧**（每秒 8 点，持续 4s，共 32）
- 撞墙即消散（不留火场）；重复命中刷新灼烧时间

### 三技能「领域展开·伏魔御厨子」（大招）
- CD 35s，开局即可用，持续 8s
- 范围：以宿傩为圆心、半径 300 的圆（有可视边界，球弹出圈外就安全）
- 效果：每 0.1s 对范围内敌人释放一次**原值 15% 的解**（22 × 0.15 = 3.3）
- 全中理论值 264；球在圈内时间占比约 45%~70% → **实际期望 120~180**
- 弹幕伤害 → 无下限可以逐跳免疫

### 被动「领域展延」
- 宿傩每次攻击结算时 **20% 概率变为直伤**（无视无下限）
- 以此法命中的敌人，**全技能当前冷却/充能进度 +0.1s**
- 只推迟已消耗的 CD 条，不消耗充能点

## 5. 表现与手感

**米白简约基调**：背景 `#F7F3EA`，场地细墨线 `#2B2B2B`，柔和阴影、无霓虹、无暗黑科技风。

| 角色配色 | 球体 | 主色 |
|---|---|---|
| 五条悟 | 白→冰蓝径向渐变，白色外环 | `#3B82F6` |
| 宿傩 | 米白→暗红渐变，黑色纹路 | `#8B1A1A` |

**技能配色**：苍 `#3B82F6` / 赫 `#8B1A1A` / 茈 `#7C3AED` / 解 银白 `#94A3B8` / 捌 暗红网格 / 灶·开 火焰 `#EA580C` / 黑闪 `#1A0000 + #FF0033`

**特效时间线（每次技能释放）**
1. 镜头 zoom → 1.02~1.03（大招 1.15，茈炸开 1.12）
2. **时间暂缓只有大招和黑闪才有**（大招 0.25 / 1.1s，黑闪 0.28 / 0.7s）——
   普通技能实测曾经占掉一局 40% 的时间，玩起来是"一卡一卡"的，已改掉
3. 技能名大字从下弹入、上方淡出（中文为主，大招附罗马音小字）
4. 音效 + 语音同时触发
5. 轻微白闪 + 屏幕震动

**黑闪**：全屏黑红闪光 + 时间暂缓 0.7s + 强震屏 + 专属音效 + 触发方球体黑红描边 + 血量条回满动画 + CD 全部瞬间充满的视觉反馈。

**其他**：伤害飘字可开关；命中轻微震屏；结算界面显示伤害构成（各技能贡献占比）。

## 6. 操作

| 平台 | 操作 |
|---|---|
| PC | `Q` = 一技能，`W` = 二技能，`E` = 三技能（大招），`ESC` 暂停，`R` 重开，`F` 全屏 |
| 手机 | 场地下方三个大圆形按钮（横屏），按住有按压反馈；技能图标上显示充能点 / CD 环 |
| 布局 | 手机横屏为佳（场地是正方形）；竖屏时场地自适应缩小、按钮移到下方 |

按钮上实时显示：**充能点数量**（五条悟的两个充能技能）、**CD 环形进度**、**灰化状态**。

## 7. 界面流程

```
主菜单 → 角色选择（左/右两个槽位，可任选五条悟或宿傩）
       ↓ 角色选择界面内含：立绘占位球 + 血条演示 + 3 技能 + 被动，
         点任意技能展开完整描述（名称/类型/CD/充能/伤害/机制）
       ↓ 点击"开始对决"
对战（3-2-1 倒计时 → 开打）→ 结算（胜者大字 + 伤害构成 + 再来一局 / 换角色）
```

设置项：音效音量 / 语音音量 / 伤害飘字开关 / 镜头晃动强度 / **黑闪概率调试倍率（测试用，默认 ×1）**。

## 9. 开发阶段划分

| 阶段 | 内容 | 产出 | 可验证 |
|---|---|---|---|
| **1** | 战斗核心 + 渲染 + 两角色全技能 + AI | 浏览器里能打完整一局 | 打开 `index.html` 直接玩 |
| **2** | 特效/慢放/镜头/黑闪演出 + 完整音效 + 语音接入层 | 手感与观感成型 | 玩一局看演出 |
| **3** | 角色选择/技能说明/结算/设置 + 手机触屏适配 | 完整游戏 | 手机浏览器横屏试玩 |
| **4** | Electron 打包 exe | `新宿对决 Setup.exe` + 免安装版 | 双击安装运行 |
| **5** | Capacitor → apk | `.apk` 安装包 | 手机安装（**需先装 Android SDK + JDK 17**） |
| **6** | `sim.js` 批量模拟 + 数值微调 | 胜率报告 + 调整后的数值表 | 跑 500 局出胜率 |
| 可选 | PWA（手机添加到主屏幕，离线可玩） | 免 SDK 的手机分发现状 | 手机浏览器打开即用 |

**关于 apk 的现实情况**：本机当前没有 Android SDK，JDK 只有 8（需要 17）。
阶段 5 需要你先安装 Android Studio（约 3–5GB）或 Android Command Line Tools + JDK 17；
在你装好之前，我会先把 Capacitor 工程和配置全部就位，并提供 PWA 版本让手机**现在就能玩**。

## 11. 需要你确认 / 知晓的点

1. **数值全是我填的**（原需求留空的部分）：五条悟大招 40s、苍/赫充能 3.2s、无下限 6.5s×3、
   解 2.2s、捌 4.0s、灶·开 11s、伏魔御厨子范围半径 300。先按这套做出可玩版本，再用 `sim.js` 调。
2. **开局所有技能（含大招）都是就绪状态** —— 开局第一波交火很燃，一局 60~90 秒大概能放 2 次大招。
3. **大招必中**：因为球无法走位，无量空处是"必中 100 点直伤"；伏魔御厨子则靠球的随机弹射决定圈内时间。
4. **黑闪在球球碰撞时按 2.5% 触发**，伤害 8^2.5 ≈ 181 点，约一半的对局能见到一次 ——

5. **apk 已经能一键出包**：`powershell -ExecutionPolicy Bypass -File tools\build-apk.ps1`（见 `docs\APK制作指南.md`）。
