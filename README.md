# 新宿对决 · SHINJUKU SHOWDOWN

一个**弹球对战**游戏：你和对手各操控一个会弹性反弹的能量球，在方框里对撞。
**双方都无法操控球的移动** —— 你唯一能做的是在正确的时机按下技能。
五条悟 / 宿傩 / 虎杖悠仁，任选两边，单局定胜负。

```
        ⬤ 五条悟 1000HP      宿傩 1200HP      虎杖悠仁 800HP ⬤
   ┌──────────────────────────────────────────────┐
   │                                              │
   │        ◎ 苍 ──→                    ✕ 解      │
   │                     ⬤            ⬤          │
   │        ⬤ 无下限                              │
   └──────────────────────────────────────────────┘
      Q 苍/赫      W 无下限      E 无量空处
```

## 立刻开始玩

| 方式 | 怎么做 | 说明 |
|---|---|---|
| **独立窗口（推荐）** | 双击根目录的 **`新宿对决.exe`** | 打包好的独立程序，原生窗口，不需要浏览器 |
| **独立窗口 + 最新代码** | 双击 **`启动游戏（独立窗口）.vbs`** | 同样不开浏览器，但直接跑 `src\` 里的代码，改完立刻生效 |
| 网页版 | 双击 `src\index.html` | 用浏览器打开，适合快速看一眼 |
| 手机 | `npm run web`，手机浏览器打开终端打印的地址 | 同一个 WiFi；可「添加到主屏幕」离线全屏玩 |

细节见 [`启动说明.md`](启动说明.md)。

## 操作

| 平台 | 操作 |
|---|---|
| PC | `Q` `W` `E`（或 `1` `2` `3`）释放三个技能 · `ESC` 暂停 · `R` 重开 · `F` 全屏 |
| 手机 | 点屏幕下方的三个大按钮（横屏体验最好） |

技能按钮上会显示**充能点**（一排小圆点）或**CD 环形进度**，转好了会亮一下。

## 规则速览

- **球会自己弹**：撞墙不减速（完全弹性），球撞球双方各吃 4 点伤害
- **弹幕 vs 直伤**：五条悟的「无下限术式」只能免疫*弹幕*；
  *直伤*（球体碰撞、黑闪、无量空处、被宿傩「领域展延」强化过的命中）免疫不了
- **黑闪**：每次球球碰撞，每个角色独立有 **2.5%** 概率打出黑闪（概率已锁定，不开放调节）——
  伤害变成 4^2.5 = 32 点，自己血量回满、技能 CD 全恢复。
  一局平均只有约 7 次碰撞，所以这是真正的稀有奇观（想先看演出效果：
  设置 → 黑闪概率倍率 → 调到 1000）
- **赢法**：把对手血量打到 0

完整数值见 [`docs/数值表.md`](docs/数值表.md)。

## 项目结构

```
新宿对决/
├─ src/                        游戏本体（浏览器直接打开就能玩）
│  ├─ index.html
│  ├─ style.css                米白简约 UI
│  ├─ main.js                  主控制器（串起逻辑/表现/音频/UI）
│  ├─ data/characters.js       ★★★ 全部数值都在这里，改平衡只改这个文件
│  ├─ core/                    math 数学 · loop 固定步长主循环 · audio 音效+语音 · fx 特效
│  ├─ game/                    ★ 纯逻辑层（无 DOM，可无头模拟）
│  │  ├─ ball.js  projectile.js  field.js
│  │  ├─ skills/gojo.js  skills/sukuna.js
│  │  ├─ ai.js  match.js       ← match.js 是战斗核心
│  ├─ render/renderer.js       Canvas 绘制
│  ├─ ui/ui.js                 界面/角色选择/技能说明/结算/设置
│  └─ assets/audio/sfx/        27 个内置音效（程序化合成）
│     assets/audio/voice/      ★ 你把自己的语音丢这里（见下）
├─ tools/
│  ├─ sim.js                   无头批量模拟：机器 vs 机器跑胜率
│  ├─ smoke.js                 真浏览器无头冒烟测试 + 场景截图
│  ├─ serve.js                 本地静态服务器（手机玩用）
│  ├─ scan_voice.js            扫描语音文件夹生成清单
│  ├─ gen_sfx.py               音效合成脚本（numpy，可重跑）
│  └─ gen_icon.py              生成图标（ico + pwa png）
├─ electron/main.cjs           exe 入口
├─ docs/                       数值表 / 语音命名规范 / 打包说明 / 设计案
└─ dist/                       打包产物（exe）
```

**架构上最重要的一点**：`src/game/` 里是纯逻辑、不碰 DOM，
所以同一份战斗代码既能跑在浏览器里，也能在 Node 里以固定步长 60Hz 无头模拟 ——
这才有 `tools/sim.js` 的胜率测试。

## 常用命令

```powershell
npm run web        # 起本地服务器（手机玩）
npm run sim        # 无头跑 2000 局平衡模拟
npm run test       # 真浏览器冒烟测试（跑 4 种对局组合，0 报错才算过）
npm run shots      # 生成 4 张场景截图到 tools/shots/
npm run voice      # 扫描你加的语音，生成清单 + 缺漏报告
npm run icon       # 重新生成图标
npm run dist       # 打包 Windows exe（安装版 + 免安装版）
```

`tools/sim.js` 的常用参数：

```powershell
node tools/sim.js --n 3000                  # 跑 3000 局（500 局样本波动有 ±4%，别省）
node tools/sim.js --p1 sukuna --p2 gojo     # 换边（检查槽位偏差）
node tools/sim.js --trace 1                 # 打印一局的完整伤害/释放事件流
node tools/sim.js --bfm 1000                # 黑闪概率 ×1000（测演出）
```

## 加语音（这是给你自己动手的部分）

音效我已经全做好了。语音你自己裁动漫片段，按下面命名丢进去就行：

```
src/assets/audio/voice/五条悟/苍_1.mp3      苍_2.mp3      ← 多条会随机播
src/assets/audio/voice/五条悟/无量空处_1.mp3
src/assets/audio/voice/宿傩/解_1.mp3
src/assets/audio/voice/宿傩/伏魔御厨子_1.mp3
```

然后跑一次：

```powershell
npm run voice
```

它会生成清单并告诉你**哪些键已有、哪些还缺、哪些名字对不上**。

完整的语音键列表（一字不差才行）见 [`docs/语音与音效命名规范.md`](docs/语音与音效命名规范.md)。

> 没有语音文件也完全没问题：游戏会安静地只放音效，不会报错。

## 已知限制

- **apk 还没生成**：本机没有 Android SDK，且只有 JDK 8（需要 17）。
  工程配置（`capacitor.config.json`）已就位，环境装好后 `npx cap add android` 一条命令出包。
- **黑闪**：2.5% × 每局约 14 次碰撞 × 双方各判一次 ≈ **约一半的对局会出现黑闪**。
  但如果你想在朋友面前"演"一次，用设置里的调试倍率。
- **球无法操控移动**：这是玩法核心，不是缺失功能。
